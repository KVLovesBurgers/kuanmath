# 吳寬 · 寬數（kuanmath）

Personal teaching site for 吳寬老師 — Traditional Chinese primary, optional EN toggle.

Static site (HTML + CSS). Visual language: dark academic ink / steel / paper (Noto Sans/Serif TC), aligned with [kuan-weekly](https://kuan-weekly.vercel.app).

## Sections

- Hero + stats (11→58, 50→80, MSU·PSU·OSU)
- **寬數週練** product block (links to kuan-weekly)
- About, tracks, experience, features, results
- Consult (mailto / tel) — no remittance account on this page

## Local

Open `index.html` or:

```bash
npx serve .
```

## Deploy

```bash
npx vercel --prod --yes
```
